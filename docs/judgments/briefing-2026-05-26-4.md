### Template — no-params marker

```csharp
namespace MagicAST.AST.Effects.Keyword;

using System.Text.Json.Serialization;
using MagicAST.AST.Effects.Traits;
using MagicAST.Serialization.DiscriminatorAttributes;

/// <summary>
/// Deathtouch (Rule 702.2). A keyword ability that causes damage dealt by an
/// object to be especially effective: any nonzero amount dealt to a creature
/// destroys it.
/// </summary>
[OracleEffect("deathtouch")]
public sealed record DeathtouchEffect : Effect, IOptionalEffect, IDurativeEffect, IPreventableEffect
{
  public bool IsOptional { get; init; }

  [JsonIgnore(Condition = JsonIgnoreCondition.WhenWritingNull)]
  public Effect? IfYouDo { get; init; }

  [JsonIgnore(Condition = JsonIgnoreCondition.WhenWritingNull)]
  public Effect? IfYouDoNot { get; init; }

  [JsonIgnore(Condition = JsonIgnoreCondition.WhenWritingNull)]
  public Duration? Duration { get; init; }

  [JsonIgnore(Condition = JsonIgnoreCondition.WhenWritingNull)]
  public UnlessClause? UnlessClause { get; init; }
}
```

Pattern: copy `VigilanceEffect.cs`, change name, change discriminator, change docstring.

### Template — cost-bearing

```csharp
namespace MagicAST.AST.Effects.Keyword;

using System.Text.Json.Serialization;
using MagicAST.AST.Costs;
using MagicAST.AST.Effects.Traits;
using MagicAST.Serialization.DiscriminatorAttributes;

/// <summary>
/// Ward (Rule 702.21). A triggered ability that counters spells or abilities
/// targeting the permanent unless the controller pays the ward cost.
/// </summary>
[OracleEffect("ward")]
public sealed record WardEffect : Effect, IOptionalEffect, IDurativeEffect, IPreventableEffect
{
  public required Cost Cost { get; init; }

  // ... standard trait fields ...
}
```

**Cost decision:** use `Cost?` (nullable) ONLY if there's a printed oracle variant without a cost. Otherwise `required Cost`. Check the corpus before deciding:

```bash
jq -r '.[] | select(.oracle_text != null) | select(.oracle_text | test("\\bWard\\b")) | .oracle_text' tests/magic-ast-tests/Data/_01_Raw/Datasets/External/oracle-cards.json | head -5
```

If you see `Ward {2}`, `Ward—Pay 2 life.`, `Ward—Discard a card.` — all carry a cost; use `required Cost`.

# Scope boundaries (DO NOT add this batch)

- **Ability-words** — Threshold, Landfall, Domain, Delirium, Fateful hour, Hellbent, Metalcraft, Morbid, Raid, Ferocious. These introduce conditional triggers, not pure keyword effects. They need different AST shape (a `Condition` wrapper on the triggered ability they apply to). Separate session.
- **Complex mechanics with state** — Transform (DFC), Manifest, Amass, Explore, Conjure, Cumulative upkeep, Affinity (cost reduction), Convoke (alt-cost), Equip (cost + attachment state). Each needs structural design. Separate sessions.
- **Token-name "keywords"** — Treasure, Food, Clue, Powerstone, Blood, Gold. These are token types, already covered by `CreateTokenEffect.TokenDefinition`. No AST work needed.
- **Goad / Fight** — these are one-shot effects, not permanent keywords. Different AST shape (already covered by other effect types likely).
- **Flash** — partially covered by `timingModification`; design question for a separate session.
