## F1 — Untap self (`UntapEffectRule.cs`, EXTEND)
- **Cards:** Simic Ragworm (`{U}: Untap this creature.`), Grim Monolith (artifact, full card: doesn't-untap + mana + `{4}: Untap this artifact.`).
- **Signal:** `UnparsedEffect`. Existing `UntapEffectRule` handles "Untap target X" but not the self-reference "Untap this {creature|artifact}".
- **CR 701.26b:** "To untap a permanent, rotate it back to the upright position from a sideways position. Only tapped permanents can be untapped."
- **Scope:** extend `UntapEffectRule` to emit `UntapEffect` with `Target = ObjectReference{Kind = Self}` (mirror how other self-targeting effects encode "this"). Grim Monolith's other lines (`DoesntUntapEffect`, `AddManaEffect`) already parse — model them per existing fixtures.
