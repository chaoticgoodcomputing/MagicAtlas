# MAST TDD — Batch 3 briefing (2026-05-28)

Batch 3 of 20. Surface has shifted from whole-card keyword flips to composite spells, anthems, ETB/upkeep triggers, and a few newer keywords (yields now fractional). DFCs and devotion/Class/leveler shapes are deliberately excluded (need infra). All 20 families create/extend distinct files.

## Invariants (all agents)
MAST DESCRIBES, does not execute. Gold = correct-parser output — NEVER `unparsed`/Diagnostics/Pattern/SourceSpan/RawText; never edit a fixture to pass. Card-scope: model EVERY ability (other lines via existing AST). PascalCase props / camelCase discriminators (reuse existing — check GLOSSARY.md). Do NOT edit infra (OracleParser, AbilityParserRegistry, PolymorphicReflectionConverter, OracleTokenizer, KeywordCombinators, RuleRegistry, parser BODIES, [PolymorphicBase]) or GLOSSARY.md. Reflection auto-discovers `[Keyword]`/`[SpellRule]`/`[StaticRule]`/`[TriggeredRule]`/`[TriggerConditionRule]`/`[Activated*Rule]` files. Reference keyword pattern: CyclingEffect.cs + CyclingKeyword.cs.

## (A) Keywords (new effect node + keyword combinator, Cycling-clone pattern unless noted)
1. **Escalate** (Rule 702.121, glossary confirms) — "Escalate {cost}" / "Escalate—[non-mana cost]". New `EscalateEffect{ Cost }`. Fixture: Collective Defiance ("Escalate {1}" + a modal "Choose one or more —" spell; if the modal line doesn't parse, gold-model only what existing AST supports and pick the cleanest Escalate fixture, or bail the modal line per sibling rules). Many Escalate cards are modal — prefer the simplest (e.g. Ride Down, Burn Away). Record cost only.
2. **Increment** — newer keyword (glossary: "put a +1/+1 counter whenever you [cast a spell paying more than its cost]"). "Increment" is a BARE keyword (no cost). `Tier=Simple`, combinator `Keyword("Increment")+OptionalReminder`. New `IncrementEffect{}` (no cost). Fixture: Cuboid Colony (Flash / Flying, trample / Increment) — model Flash + Flying/trample via existing keywords.
3. **Mayhem** — newer keyword (glossary: "play cards you discarded this turn from your graveyard"), printed "Mayhem {cost}". New `MayhemEffect{ Cost }`. Fixture: Swarm, Being of Bees (Flash / Flying / Mayhem {B}). Record cost only; the discard/graveyard-cast is reminder.
4. **Support (keyword action)** (Rule 701.42, glossary confirms) — "support N" is a keyword ACTION appearing inside a triggered ability: "When this creature enters, support 2." New `SupportEffect{ Quantity N }` (put a +1/+1 counter on each of up to N OTHER target creatures). Add it as a triggered EFFECT rule `[TriggeredRule]` (the ETB trigger already parses). Fixture: Expedition Raptor (Flying + "When this creature enters, support 2."). Reuse PutCountersEffect if it can express "+1/+1 counter on each of up to N other creatures"; else create a tight SupportEffect.

## (B) Composite spell families (new `[SpellRule]` under Spell/Rules/; reuse existing effects)
5. **Damage to any target + gain life** — Sacred Fire ("Sacred Fire deals 2 damage to any target and you gain 2 life." + Flashback which already parses). Use DealDamageEffect + GainLifeEffect (two effects in the spell ability). New [SpellRule].
6. **Pump + gain keyword (spell)** — Dive Down ("Target creature you control gets +0/+3 and gains hexproof until end of turn."). ModifyPTEffect + GainAbilityEffect (hexproof) on the target, untilEndOfTurn. New [SpellRule].
7. **Destroy land + controller loses life** — Spreading Rot ("Destroy target land. Its controller loses 2 life."). DestroyEffect + LoseLifeEffect (the land's controller). New [SpellRule].
8. **Target player loses N and you gain N (drain)** — Absorb Vis ("Target player loses 4 life and you gain 4 life." + Basic landcycling which already parses). LoseLifeEffect(target player) + GainLifeEffect(you). New [SpellRule].
9. **Destroy N target lands** — Rain of Salt ("Destroy two target lands."). DestroyEffect with a count/two-target shape (consult GLOSSARY for how multiple targets / "two target" are expressed; mirror an existing "destroy two target" rule if present). New [SpellRule].

## (C) Triggered families (new `[TriggeredRule]`/`[TriggerConditionRule]`; reuse effects)
10. **ETB create two tokens + cast-trigger** — Teeming Dragonstorm ("When this enchantment enters, create two 2/2 white Soldier creature tokens." + "When a Dragon you cast..."/second trigger). The ETB-create-two-tokens uses CreateTokenEffect (count=2); the 2nd trigger via existing rules or ONE tight sibling. Two abilities — model both.
11. **ETB target creature can't block this turn** — Smoldering Spires ("This land enters tapped." [parses] + "When this land enters, target creature can't block this turn."). Use existing CantBlockEffect on a target creature, this-turn duration. New [TriggeredRule] effect rule.
12. **Whenever you draw your second card each turn** — Lat-Nam Adept ("Whenever you draw your second card each turn, put a +1/+1 counter on this creature."). New [TriggerConditionRule] for "draw your second card each turn" (check TriggerEvent enum first) + existing PutCountersEffect.
13. **ETB exile target land + LTB return** — Petravark ("When this creature enters, exile target land." + "When this creature leaves the battlefield, return the exiled card..."). ETB ExileEffect(target land); the LTB-return-exiled is a paired/linked ability — model the ETB exile; for the LTB use existing return-from-exile AST if present, else ONE tight sibling. If the linked-exile needs new AST, bail the LTB line per sibling rules and pick a cleaner exemplar, OR model descriptively.
14. **Conditional each-upkeep create token** — Pest Rescuer ("At the beginning of each upkeep, if you don't control a Pest creature token, create a 1/1 ... Pest ... token."). "Beginning of each upkeep" timing + an intervening-if condition + CreateTokenEffect. Consult GLOSSARY for the intervening-if/condition shape on triggered abilities.

## (D) Static families (new `[StaticRule]`; reuse effects)
15. **Enchantment ETB choose creature type + chosen-type anthem** — Etchings of the Chosen ("As this enchantment enters, choose a creature type." + "Creatures you control of the chosen type get +1/+1."). REUSE the existing `ChooseCreatureTypeOnEntryEffect` (landed batch 2 — read it) for line 1; line 2 is an anthem (ModifyPTEffect over "creatures you control of the chosen type" — a filter referencing the chosen type). New [StaticRule](s).
16. **Other-creatures anthem + granted keyword** — Thunderclap Wyvern ("Flash / Flying / Other creatures you control get +1/+1 and have flying."). The "Other creatures you control get +1/+1" base anthem already parses (see AggressiveMammoth fixture). The gap is "and have flying" (anthem + granted keyword). Extend or add a [StaticRule] combining ModifyPTEffect + GainAbilityEffect over the team filter.
17. **Self +N/+0 for each other [subtype]** — Rat Colony ("This creature gets +1/+0 for each other Rat you control." + "A deck can have any number..." which is a deckbuilding note — model via existing AST or it may already be ignored/parsed). Reuse the SelfPTForEach pattern (exists) with a per-other-subtype CountQuantity.
18. **All creatures have [keyword]** — Mass Hysteria ("All creatures have haste."). Global grant: GainAbilityEffect (haste) over an ObjectFilter for all creatures. New [StaticRule].
19. **Equipped creature has [kw] and [kw]** — Fleetfeather Sandals ("Equipped creature has flying and haste." + "Equip {2}" which already parses). Static granting TWO keywords to equipped creature. Consult how existing "Equipped creature has [keyword]" is modeled (grep fixtures) and extend to two keywords.
20. **Flash + Aura (enchant + enchanted-gets)** — Aether Meltdown ("Flash" [parses] + "Enchant creature or Vehicle" + "Enchanted creature or Vehicle gets -4/-0."). Model the enchant restriction + the enchanted-object static debuff via existing Aura AST (grep an existing Aura fixture, e.g. a -X/-0 aura). New [StaticRule] if the enchant-target "creature or Vehicle" disjunction is the gap.
