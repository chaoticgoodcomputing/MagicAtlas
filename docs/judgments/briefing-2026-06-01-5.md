## F1 — "Enchanted/Equipped [perm] has \"[quoted ability]\"" grant (Ephara's Radiance, Sadistic Obsession) — JUDGE
- **Signal:** FY 12.3 (top buildable). Highest-FY chip family — closing it advances many Auras/Equipment.
- **CR 113.6** (verbatim, excerpt): "Abilities of all other objects usually function only while that object is on the battlefield…" — a granted ability is a full-fledged ability of the gainer.
- **AST (no new node):** `GainAbilityEffect.GainedAbility` is ALREADY `required Ability` (a recursive structured ability — read its doc). The gap is the **parser rule**: recognize "Enchanted/Equipped [perm] has \"[X]\"" → `GainAbilityEffect{ Target: EnchantedOrEquipped, GainedAbility: <parse the quoted text X as an Ability> }`. Delegate the quoted text to the existing ability parsing; both exemplars' quoted abilities are simple activated abilities that already parse (`{1}{W},{T}: You gain 3 life` / `{B},{T}: Put a -1/-1 counter on target creature`). "This creature" inside the quote refers to the enchanted permanent.
- **Anti-patterns:** don't free-text the quoted ability — parse it into a real `Ability`; don't drop the EnchantedOrEquipped subject; if the quoted ability genuinely fails to parse, STOP (don't emit unparsed).

## F2 — ETB optional tutor-to-top (Dune Mover, Boggart Harbinger) — opus
- **Signal:** DY 6 / DY 5 (two clusters, same shape). "When this creature enters, you may search your library for a [basic land card | Goblin card], reveal it, then shuffle and put that card on top."
- **CR 701.23a** (verbatim): "To search for a card in a zone, look at all cards in that zone (even if it's a hidden zone) and find a card that matches the given description."
- **AST (no new node):** reuse `SearchLibraryEffect` (read it for the destination/reveal/shuffle fields and how "put on top" is expressed). The ETB is optional ("you may"). The two exemplars vary the search filter (basic land vs Goblin/subtype card). Toxic (Dune Mover) parses already.
- **Anti-patterns:** the optional "you may" is structured (`OptionalEffect`/flag), not dropped; the search filter is structured; destination is "top of library", not free text.

## F3 — Deck-construction "A deck can have any number of cards named [this]" (Rat Colony) — NEW NODE, JUDGE
- **Signal:** DY 5. The count-pump line already parses (SelfPTForEachRule); this deck-construction line is the only gap.
- **CR 100.2a** (verbatim, excerpt): "…A constructed deck may contain any number of basic land cards and no more than four of any card with a particular English name other than basic land cards." — this card grants itself an exception to the four-of rule.
- **AST:** no existing node fits. Author a small descriptive node (e.g. `DeckConstructionEffect` / `AnyNumberInDeckEffect`, discriminator like `anyNumberInDeck`) recording the self-referential exception. Field-less or a self-name marker; descriptive only (deck-building is engine/format territory). Follow the minimal-node pattern (look at a field-less effect like `InvestigateEffect`). Covers Relentless Rats, Shadowborn Apostle, Persistent Petitioners, Dragon's Approach.
- **Anti-patterns:** don't free-text; keep the node minimal; this is a static characteristic-defining-ish deck rule, not an activated/triggered ability.

## F7 — Count-based self-debuff "gets -N/-N for each card in your hand" (Dread Slag) — opus

- **Anti-patterns:** no new node; reuse `DerivedQuantity` (CardsInHand); the negative sign is structured, not free text.

## F8 — "Ward—Pay N life" (Sire of Seven Deaths) — sonnet
- **Signal:** DY 2. Grouped keyword lines parse; "Ward—Pay 7 life." (Ward with a life cost) is the gap.
- **CR 702.21a** (verbatim): "Ward is a triggered ability. Ward [cost] means 'Whenever this permanent becomes the target of a spell or ability an opponent controls, counter that spell or ability unless that player pays [cost].'"

- **Anti-patterns:** don't free-text the cost; reuse `PayLifeCost`; keep Ward's existing structure.
