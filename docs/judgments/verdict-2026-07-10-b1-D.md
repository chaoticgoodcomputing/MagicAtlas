## FAIL verdicts

### mast-tdd/2026-07-10-dont-untap-static — Hokori, Dust Drinker
**Verdict:** FAIL
**Issue:** the line-2 triggered ability drops the "each player's upkeep" scope from the trigger.
**Rule citation:** CR 502.3 (untap step); CR 109.5 ("that player").
**Rule text:** > "Normally, all of a player's permanents untap ... but effects can keep one or more of a player's permanents from untapping." (502.3) — Hokori's two halves (lands don't untap; each player untaps one land on their own upkeep) are a symmetric lock.
**What the fixture says:**
```
"Trigger": { "Timing": "At", "Event": { "Part": "Upkeep", "Edge": "Beginning" } }
```
…paired with the effect `"untap"` → `Controller: "ThatPlayer"`.
**Why this misrepresents the rule:** the oracle is "At the beginning of **each player's** upkeep, **that player** untaps a land they control." The phase-event AST carries a `Whose` axis, and every existing upkeep-trigger fixture sets it (BlessingOfLeeches/BreedingPit/HollowTrees `Whose:You`, InvasionOfEldraine `Whose:Opponent`, CurseOfThePiercedHeart `Whose:EnchantedPlayer`). Here it is omitted, so the trigger cannot express that it fires once per player, and the effect's `Controller:ThatPlayer` reference — defined by the codebase as "the player whose turn/step fired the trigger (CR 109.5)" — has no antecedent inside the AST. The each-player symmetry that defines the card is lost.
**Suggested fix:** set the trigger `Event.Whose = "Any"` (the ControllerFilter value for any/each player; the enum has no dedicated `EachPlayer`), consistent with the You/Opponent convention. If a dedicated each-player timing scope is wanted, surface to design — but `Any` is the minimum faithful fix and already exists.
**Note:** the two *new* rules on this branch are correct in isolation — `SubjectDoesntUntapDuringControllersUntapStepsRule` reuses `DoesntUntapEffect` with an `Each`/`CardTypes` subject (generalized Lands/Creatures/Artifacts/Permanents, not Hokori-literal) and is anchored; `ThatPlayerUntapsAControlledTypeTriggeredRule` reuses `UntapEffect` with `Any` + `Controller:ThatPlayer` and is anchored. The FAIL is solely the trigger-scope omission in the gold fixture.
