## FAIL verdicts

### K02 / Wildfire Howl — `WildfireHowl.json`
**Verdict:** FAIL
**Issue:** The gift-promise player choice is not restricted to an opponent.
**Rule:** CR 702.174a — "The first ability is always 'As an additional cost to cast this spell, **you may choose an opponent**.'"
**What the gold says:** `{"EffectType":"optional","Inner":{"EffectType":"choosePlayer"}}` — no `Scope`.
**Why this misrepresents the rule:** "opponent" is a load-bearing, closed restriction (you cannot promise the gift to yourself). It survives only in the verbatim, unparsed reminder text; the structured `choosePlayer` reads "choose any player". The `GiftKeyword` doc-comment consciously defends this ("the opponent restriction is inherent to the gift keyword, so the reused ChoosePlayerEffect carries the declaration only") — but the structure to express it exists (K03 adds `ChoosePlayerEffect.Scope`). This is NOT the merge-dependency exemption: that exemption applies when the gold *does* set `Scope:Opponent` and only the node file lags. Here the gold omits it entirely.
**Suggested fix:** Set `choosePlayer.Scope = "Opponent"` (merge-coordinate with K03's new nullable `Scope` field). Everything else on the card is faithful — `GiftEffect`, `GiftPromisedCondition`, and the `giftPromised -> (1 to any target + 2 to each creature) ELSE (2 to each creature)` conditional body are correct; all cited 702.174 subrules (b/e/j/k) verified in rules-structure.json.

### K09 / Éowyn, Lady of Rohan — `EquipAbilityYouActivateCostReductionRule.cs`
**Verdict:** FAIL
**Issue:** Wrong CR citation for the cost reduction (known bug; orchestrator to remediate).
**Rule:** cited `CR 118.9` — but 118.9 is **alternative costs** ("Some spells have alternative costs... its controller may pay rather than paying the spell's mana cost"), a different mechanic. Correct = **CR 118.7** ("What a player actually needs to do to pay a cost may be changed or **reduced** by effects") / **118.7a** (generic-mana reductions).
**What the file says:** `/// CR 118.9 (cost alterations): "Some effects reduce the cost to cast a spell or activate an ability."` — the quoted prose is not even 118.9's actual text.
**Why this misrepresents the rule:** an equip-ability `{1}`-less reduction is a cost reduction (118.7), not an alternative cost (118.9).
**Suggested fix:** Re-cite CR 118.7 / 118.7a. Rest of Éowyn is faithful: `CostReductionEffect{AppliesTo: activatedAbility Equip/You}`; combat trigger `modal(first strike|vigilance)` + `conditional(objectIsEquipped -> composite of both, "instead")`; `ObjectIsEquippedCondition` well-shaped (cites CR 702.6 Equip — acceptable; CR 301.5a defines "equipped creature" more precisely — noted, not a FAIL).
