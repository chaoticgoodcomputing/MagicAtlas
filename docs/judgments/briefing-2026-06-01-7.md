## F1 — ETB flicker "exile [perm] you control, then return it" (Felidar Guardian [5 combos], Restoration Angel) — JUDGE
- **CR 603.6a** (ETB) + **CR 603.2** (triggered).
- **AST:** ETB `TriggeredAbility`, effect is the **flicker**: `ExileEffect`(target = "another target permanent you control" / "target non-Angel creature you control", **optional** "you may") **then** `ReturnToBattlefieldEffect` whose subject is the just-exiled card — reuse the `ObjectFilter.ExiledWith` linkage (the Petravark/`MayCastExiledWithSelfRule` precedent; a `{Zone:Exile, ExiledWith:{Kind:Self}}` reference), `UnderControl` = owner/your. Likely a `CompositeEffect[Exile, Return]` wrapped optional. Read `ExileEffect`/`ReturnToBattlefieldEffect`/the `ExiledWith` reference.
- **Anti-patterns:** "then return that card" is the LINKED exiled reference (`ExiledWith`), not free text; the "you may" is structured optional; don't drop the target filter.

## F3 — copy-token with modifications (Kiki-Jiki, Mirror Breaker [combos], Helm of the Host) — JUDGE
- **CR 707.2** (verbatim, excerpt): "When copying an object, the copy acquires the copiable values of the original object's characteristics…" + **CR 111.1** (tokens).
- **AST:** reuse `CopyEffect` (read it — it has `Target`, `Count`, `Modifications: List<CopyModification>`, `MayChooseNewTargets`). "Create a token that's a copy of [target nonlegendary creature you control | equipped creature], except [it has haste | it isn't legendary]" → `CopyEffect{ Target, Modifications:[…] }` (the "except" clauses are `CopyModification`s — read `CopyModification.cs`; add a modification kind only if the needed one is absent). Kiki: activated `{T}:`, Target = nonlegendary creature you control, mod = gains haste, **plus a delayed sacrifice** "Sacrifice it at the beginning of the next end step" (`CreateDelayedTriggerEffect` — read it). Helm: combat-trigger, Target = equipped creature, mods = not-legendary + haste.
- **Anti-patterns:** the "except …" clauses are structured `CopyModification`s, not free text; Kiki's delayed-sac is a structured delayed trigger; reuse `CopyEffect`. If you add a `CopyModification` kind, that's a node change → regen schema.
