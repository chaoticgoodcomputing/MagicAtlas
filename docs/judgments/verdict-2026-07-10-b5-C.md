**Issue:** Wrong CR citation in the doc-comment.
**What it says:** "granting the Changeling characteristic-defining ability (CR 205.3m …; **CR 702.6 — Changeling as an ability grant**)"
**Rule text:** CR 702.6 in rules-structure.json = **"Equip"** (not Changeling). Changeling is **CR 702.73 / 702.73a** ("'Changeling' means 'This object is every creature type.'") — which the same comment already cites correctly.
**Why it misrepresents:** 702.6 is the Equip keyword rule; citing it as the authority for a Changeling grant is a contradictory citation (the rule's actual text is a different keyword). This is not parent-vs-subrule imprecision; 702.6 and 702.73 are distinct keyword rules.
**Modeling (correct):** ModifyPTEffect +1/+1 on EnchantedOrEquipped + a **structured** GainAbilityEffect wrapping a Changeling StaticAbility/KeywordAbilityEffect (no free text); Equip {2} → activated ability, mana {2}, attach target creature you control, OnlyAsSorcery. Anchored matcher captures only Runed Stalactite + Amorphous Axe (same "[Equipped/Enchanted] creature gets +N/+M and is every creature type" template); correctly declines Arachnoform ("…, has reach, and is every creature type" compound).
**Suggested fix:** Delete the "CR 702.6 — Changeling as an ability grant" clause (or change 702.6 → 702.73). One-line doc-comment edit; no re-model.

**Suggested fix:** Change "CR 611.2" → "CR 611.3". One-line doc-comment edit; no re-model.
