## Cluster 1: EntersTapped — 225 marginal flips

**Template:** `<SUBTYPE> <TYPE> enters tapped.`

**Card-shape:** lands whose oracle includes the line `This land enters tapped.` (alongside a tap-for-mana ability). The entire class of "comes into play tapped" lands.

**AST design** (helper-novel call):
- Option A: New `EntersTappedEffect : Effect` with discriminator `entersTapped`. Static-ability-attached effect that records "this permanent enters tapped."
- Option B: New `EntersTappedReplacementEvent : ReplacementEvent` if the existing replacement-event infrastructure is the right home. Rule 614 ("Replacement Effects") makes this technically a replacement: "If this permanent would enter the battlefield, it enters tapped instead."
- Recommendation: **Option A** (descriptive, simpler). MAST records *what the oracle says* — a static property — not the replacement-effect machinery the rules engine derives.

**Fixture candidates** (from raw corpus jq query — these are "tapped land" + mana-ability cards; you'll need to fixture the full oracle including the tap-ability):
1. **Foot Headquarters** — `This land enters tapped.\nWhen this land enters, you gain 1 life.\n{T}: Add {W} or {B}.`
   (NOTE: this overlaps with cluster 4 too — would fixture both shapes in one card)
2. **Swiftwater Cliffs** — same shape, U/R colors
3. **Kazandu Refuge** — same shape, R/G colors
4. **Akoum Refuge** — same shape, B/R colors

If you want a purely-tapped-no-lifegain example, search for lands with EXACTLY `This land enters tapped.\n{T}: Add {X}.` (no lifegain line). Common pattern; many old dual lands.

## Cluster 2: Bare-keyword lines — 127 marginal flips

**Template:** `<KW>` (a single keyword on a line by itself)

**Card-shape:** Most are single-keyword oracle lines like `Cascade`, `Defender`. Existing keyword effect types (Flying via `EvasionEffect`, Vigilance via `VigilanceEffect`) already parse cleanly when standalone. The failures are keywords WITHOUT corresponding effect types.

**AST design**:
- Add `DefenderEffect : Effect` (discriminator `defender`, no parameters). Rule 702.3 — "this creature can't attack." MAST records keyword presence; rules engine derives the can't-attack semantics.
- Add `CascadeEffect : Effect` (discriminator `cascade`, no parameters). Rule 702.85 — complex cast-trigger mechanic. MAST records the keyword; rules engine handles the exile-and-cast logic.

**Fixture candidates** for Defender:
- **Monoist Sentry** — `{B}` cost, 4/1, oracle: `Defender`
- **Murmuring Phantasm** — `{1}{U}`, 0/5, oracle: `Defender`
- **Carnivorous Plant** — `{3}{G}`, 4/5, oracle: `Defender`

For Cascade (need to query — Cascade spells, not creatures usually):
- Look for spells with single oracle line `Cascade` or `Cascade (reminder...)`. Many Living End / similar.

## Cluster 3: Cycling — 74 marginal flips

**Template:** `<KW> <COST> (<COST>, <SUBTYPE> this <TYPE>: <SUBTYPE> a <TYPE>.)`

**Card-shape:** `Cycling {N} ({N}, Discard this card: Draw a card.)` — keyword with mana cost + reminder text.

**AST design**:
- Add `CyclingEffect : Effect` (discriminator `cycling`) with one required field: `Cost: Cost` (mana cost to cycle). Reminder text is descriptive of the rules; not in the AST. Rule 702.32.

**Fixture candidates**:
- **Yoked Plowbeast** — Creature — Beast, oracle: `Cycling {2} ({2}, Discard this card: Draw a card.)`
- **Sandbar Serpent** — Creature — Serpent, same Cycling cost
- **Desert Cerodon** — Creature — Beast, `Cycling {R}` (colored cost variant)
- **Lurching Rotbeast** — Creature — Zombie Beast, `Cycling {B}`

These are PERFECT — single-ability creatures whose only oracle line is the Cycling keyword. P/T body + Cycling line; no other text.

## Anti-patterns / decision points for helper-novel

- **`EntersTappedEffect` vs `EntersTappedReplacementEvent`** — if you find an existing pattern in `AST/Effects/Replacement/` that fits, use it. Otherwise default to `Effect`-subtype for consistency with the other keyword effects (Vigilance, Lifelink, Indestructible).
- **`CyclingEffect.Cost: Cost` vs raw mana string** — use `Cost` (the existing polymorphic record). Cycling's cost can be non-mana in rare cases (Typecycling, Mountaincycling — same shape). Use the abstract `Cost` to allow future expansion.
- **`CascadeEffect` no-params** is fine — Cascade carries no oracle-level parameters; its semantics are entirely rules-driven.
- **Reminder text** — the parser-mech handles stripping `(reminder)` parentheticals. Helper-novel doesn't need to model reminder text in the AST; it's purely a parser concern.
